title: Agent Dash
description: A TUI dashboard for your Claude Code sessions, running in tmux or closed

Agent Dash is a terminal dashboard for [Claude Code](https://docs.anthropic.com/en/docs/claude-code) sessions. It lists the sessions running in your tmux server next to the ones that aren't, so a session you closed yesterday is one keypress from running again.

Built with [Ratatui](https://ratatui.rs), [Crossterm](https://github.com/crossterm-rs/crossterm), and [Tokio](https://tokio.rs).

## Features

- **Persistent sessions** — every session Agent Dash has seen is remembered by its Claude session ID, including closed ones. Press `o` on a closed session to resume it in a new tmux session.
- **Three ways to group** — by state (in progress, completed, need action, idle), by folder, or by date. Backtick cycles them; `S` opens the view settings.
- **Archive** — `a` hides a session from the default view. Sessions you close on purpose are archived for you.
- **Import** — `agent-dash import` pulls in existing sessions from the Claude CLI and Claude Desktop.
- **Live preview** — real-time pane output with ANSI rendering, in a dual-pane layout with configurable orientation
- **Copy mode** — vim-like motions, search, and text selection on preview content
- **Unread tracking** — a session that finishes working is marked until you look at it

## How it works

Every two seconds Agent Dash finds the tmux panes running `claude` and reads the `~/.claude/sessions/<pid>.json` file Claude Code writes for each process. That file carries the session ID, working directory, title, and busy/idle status. Agent Dash needs that file: a `claude` pane without it is not listed. See [Claude Code](/docs/agents) for the details and for how a closed session is told apart from a crashed one.

The preview uses a FIFO pipe for low-latency updates, with `tmux capture-pane` polling as the fallback. Plan and Ask prompt state is read from the last line of the pane.
