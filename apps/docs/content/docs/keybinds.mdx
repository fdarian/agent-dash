---
title: Keybinds
description: Complete keybind reference for Agent Dash
---

Press `?` at any time to see keybinds in the built-in help overlay.

## Global

| Key | Action |
|-----|--------|
| `0` | Focus preview pane |
| `1` | Focus session list |
| `o` | Switch to the session's pane, or resume a closed session |
| `O` | Attach session in popup (live sessions only) |
| `v` | Enter copy mode |
| `?` | Toggle help overlay |
| `q` | Quit |
| `Ctrl+C` | Quit |

## Session List

Every list in Agent Dash (sessions, view settings, and the picker in `agent-dash import`) navigates with `j` / `k`, `↑` / `↓`, or `Ctrl+n` / `Ctrl+p`, selects with `Enter`, and closes with `Esc`.

| Key | Action |
|-----|--------|
| `j` / `↓` / `Ctrl+n` | Next session |
| `k` / `↑` / `Ctrl+p` | Previous session |
| `Enter` | Same as `o` |
| `h` | Collapse group |
| `l` | Expand group |
| `/` | Filter sessions (fuzzy) |
| `` ` `` | Toggle active / archived sessions |
| `S` | View settings: status, grouping, last activity |
| `a` | Archive / unarchive session |
| `c` | New session: pick a folder, optionally a [mode](/docs/configuration#modes) and a new git worktree |
| `r` | Toggle read / unread |
| `n` | Edit a note for the session |
| `x` | Close the session's pane (live sessions, requires confirmation) |
| `+` | Maximize session list |
| `_` | Minimize session list |

## View Settings

Opened with `S`.

| Key | Action |
|-----|--------|
| `1` / `2` / `3` | Edit Status / Grouping / Last activity |
| `j` / `k` | Move between rows or options |
| `Enter` | Open the row, or apply the option and go back |
| `Esc` | Back out one level |

## Import Picker

Opened by `agent-dash import`. Nothing is selected to start with.

| Key | Action |
|-----|--------|
| `j` / `k` / `↑` / `↓` / `Ctrl+n` / `Ctrl+p` | Move cursor |
| `Tab` / `Shift+Tab` | Cycle the source filter: All, CLI, Desktop |
| `Space` | Toggle session |
| `a` | Select every visible session (honoring the source and text filters) |
| `n` | Deselect all |
| `/` | Fuzzy filter (`Enter` keeps it, `Esc` clears it) |
| `Enter` | Import selected sessions |
| `Esc` / `q` | Quit without importing (`Esc` clears a filter first) |

## Preview Pane

| Key | Action |
|-----|--------|
| `/` | Search forward |
| `?` | Search backward |
| `y` | Copy all content to clipboard |

## Copy Mode

Enter copy mode by pressing `v`.

### Movement

| Key | Action |
|-----|--------|
| `h` / `←` | Move left |
| `j` / `↓` | Move down |
| `k` / `↑` | Move up |
| `l` / `→` | Move right |
| `0` | Start of line |
| `$` | End of line |
| `w` | Next word |
| `e` | End of word |
| `b` | Previous word |
| `H` | Top of screen |
| `L` | Bottom of screen |
| `gg` | Top of content |
| `G` | Bottom of content |
| `zz` | Center viewport on cursor |

### Selection

| Key | Action |
|-----|--------|
| `v` | Toggle selection |
| `y` | Yank selected text |

### Search

| Key | Action |
|-----|--------|
| `/` | Search forward |
| `?` | Search backward |
| `n` | Next match |
| `N` | Previous match |
| `Esc` | Exit copy mode |

## Search Input

Active during search in copy mode or filter in help overlay.

| Key | Action |
|-----|--------|
| `Enter` | Execute search |
| `Esc` | Cancel search |
| `Ctrl+A` | Move to start |
| `Ctrl+E` | Move to end |
| `Ctrl+U` | Delete to start |
| `Ctrl+K` | Delete to end |
| `Ctrl+B` / `←` | Move left |
| `Ctrl+F` / `→` | Move right |
| `Alt+←` | Previous word |
| `Alt+→` | Next word |
| `Alt+Backspace` | Delete previous word |
